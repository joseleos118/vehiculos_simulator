# Sistema de Gestión de Vehículos

## Descripción

Sistema de gestión de vehículos desarrollado en Python para administrar una flota de coches y motos.

El proyecto aplica conceptos de programación orientada a objetos como herencia, reutilización de miembros, redefinición de métodos y polimorfismo.

## Objetivo

Crear un sistema que permita registrar, consultar, alquilar, devolver y dar de baja vehículos, además de consultar estadísticas de la flota.
